# plugins.podlesnytwins.com

Одна страница: пять плагинов Podlesny Twins и ссылки на установщики. Ни цен,
ни лицензий, ни личного кабинета — с ноября 2026 плагины не продаются и
раздаются бесплатно.

## Что где

```
index.html      единственная страница
styles.css      стили
rise.js         одно появление блоков при прокрутке (страница работает и без него)
assets/         шрифты, снимки интерфейсов, favicon
docs/           бумаги, не относящиеся к странице
CNAME           plugins.podlesnytwins.com
```

## Установщики

Лежат в GitHub Releases ЭТОГО репозитория — он публичный, поэтому ссылки
работают без авторизации. В приватном `podlesnytwins-mono` релизы тоже есть, но
их файлы требуют токен и для сайта не годятся.

Тег на продукт и версию, например `cutter-1.0.13`, `inspirator-0.12.0`:

```bash
gh release create cutter-1.0.13 путь/Cutter-Installer-v1.0.13.pkg путь/Cutter-Setup-v1.0.13.exe \
  --title "Cutter 1.0.13" --notes "Бесплатно, без лицензии и активации."
```

Ссылка на файл складывается как
`https://github.com/Podlesny-Twins/podlesnytwins-plugins/releases/download/<тег>/<имя файла>`
— её и прописываем в `index.html`.
